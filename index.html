일간 할 일

기준: 매일 초기화. 체크 상태는 나만 볼 수 있게 저장돼요.

    주간 할 일

    기준: 매주 초기화 (게임 내 실제 초기화 요일은 콘텐츠마다 달라요 — 월요일/목요일 등 직접 확인).

      월간 할 일

      기준: 매월 초기화.

        🔒 이 체크리스트는 내 닉네임으로 저장돼요. 다른 닉네임을 쓰는 사람에게는 안 보여요.

        마비노기는 '재능(탈렌트)' 단위로 성장합니다. 아래는 현재 존재하는 주요 재능과 추천 장비의 기본 틀이에요. 메타가 자주 바뀌니 실제 세팅은 최신 공략과 대조해서 편집해주세요.

        형식: 계열|재능명|주 무기·방어구 추천|비고 — 한 줄에 재능 하나. 계열은 전투 또는 생활.

        🌐 이 표는 공유 데이터입니다. 편집하면 이 페이지를 보는 모두에게 반영돼요.

        확인된 최신 정보를 기준으로 채워뒀어요 (예: 크롬 바스 → 나이트브링어 무기/아다만티움/글라스 기브넨 재료, 테흐 두인 → 페러시우스 장비). 확실하지 않은 칸은 확인 필요로 남겨뒀으니, 실제로 얻은 드랍을 채워주시면 정확도가 올라가요.

        형식: 주기|던전명|주요 드랍|비고 — 주기는 일간/주간/월간/상시 중 하나.

        🌐 이 표는 공유 데이터입니다. 편집하면 이 페이지를 보는 모두에게 반영돼요.

        경매장 시세 조회

        넥슨 오픈 API의 '경매장 정보 조회'를 이용해요. 던전 드랍 표에서 아이템 이름을 그대로 복사해서 검색해보세요.

        🔒 이 키는 내 닉네임으로 저장돼요. 다만 백엔드가 완전한 로그인 시스템은 아니라서, 신원이 확실한 사람들끼리만 공유하는 걸 권장해요.

        API 키가 없다면 openapi.nexon.com에서 애플리케이션을 등록하고 '마비노기' API 사용 동의를 받으면 발급돼요 (승인까지 시간이 걸릴 수 있어요). 브라우저에서 직접 호출하는 방식이라 넥슨 서버 정책에 따라 요청이 막히는 경우, 별도의 서버(프록시)를 두는 방식으로 바꿔야 할 수도 있어요 — 막히면 알려주세요, 그 구조로 다시 만들어드릴게요.

        내 캐릭터 장부

        엑셀처럼 원하는 만큼 캐릭터(부캐 포함)를 추가하고, 장비·무기·보유 골드·목표·메모를 자유롭게 적어두세요.

        🔒 이 페이지는 내 닉네임으로 저장돼요. 다른 닉네임을 쓰는 사람 화면에는 안 보여요. (완전한 로그인 보안은 아니니, 민감한 정보는 적지 않는 걸 권장해요.)

        Data based on NEXON Open API · 데이터는 구글 시트에 저장되며, 닉네임 단위로 구분됩니다.
